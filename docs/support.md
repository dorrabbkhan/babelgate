# Supporting babelgate

babelgate is Apache-2.0 and free to use — everything in the repository
is open. There are two ways to support it.

## Sponsor the project

GitHub Sponsors: <https://github.com/sponsors/dorrabbkhan> — the
repository's `.github/FUNDING.yml` points there. Sponsorship funds the
upstream API keys the live test suite and the weekly client replay
actually need — the checks behind
[docs/compatibility.md](compatibility.md) cost real provider money.

## Paid support contracts

Available from v1.6 (see `docs/roadmap.md` — the pricing sketch puts
team support in the v2 track and paid support contracts from v1.6). A
contract can cover: help rolling babelgate out across a team
(routing, `babelgate.yaml` review), provider adapters you need
maintained against upstream drift, and response-time commitments for
bugs.

To start a conversation, open a GitHub issue with
`[support]` in the title:
<https://github.com/dorrabbkhan/babelgate/issues/new> — or pick the
feature-request template and mention "support contract" in the body.

## Free help

- Bugs: <https://github.com/dorrabbkhan/babelgate/issues/new> (the bug
  template asks for the config and the client, never keys).
- Security problems: **privately** via the repository's Security tab —
  [SECURITY.md](../SECURITY.md). Never open a public issue for a
  security problem.
