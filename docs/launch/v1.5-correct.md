# babelgate 1.5: Correct everywhere — the translator you can check

*Draft launch post — babelgate v1.5. Owner reviews before publishing.*

Every LLM gateway promises "any client on any model". babelgate 1.5
makes a different promise: **every translation you can check**, with the
evidence published — a compatibility matrix generated from the test
suite, a weekly replay of each new Claude Code and Codex release, and an
inspector that shows exactly what the proxy changed, hop by hop.

```bash
ollama pull qwen3-coder:30b
OLLAMA_API_BASE_URL=http://localhost:11434 \
  npx babelgate --preset claude-code --target ollama --model qwen3-coder:30b
```

## What shipped

**Reasoning, for every client format.** Claude's `thinking`, Chat's
`reasoning_effort`, Gemini's `thinkingConfig`, Ollama's `think` and
Codex's `reasoning` items all map to the target's thinking control — and
the model's *signed* reasoning survives the session: Anthropic
`signature`s and Gemini `thoughtSignature`s ride back inside `bg1.`
envelopes the client already resends each turn. Reasoning only ever
returns to its origin provider — cross-provider reasoning is dropped
with a note, never silently misattributed. `reasoning: false` on a
provider restores the 1.4 behaviour byte-for-byte.

**Media that reaches the model.** URL images, PDF documents and images
inside tool results translate across all five formats — Claude Code's
PDF-and-screenshot tool results included. A target that needs bytes gets
them fetched under an SSRF guard (no private addresses, 20 MB / 15 s
caps, bytes never logged); a target that can't take a document gets a
400 in the client's own dialect, never a silent drop.

**A shim for native endpoints.** Ollama, LM Studio, DeepSeek, z.ai and
Kimi all serve Anthropic Messages now — but each leaves gaps. Declare a
provider `preset` (or its `gaps` by hand) and babelgate passes requests
through untouched except the fixes: `count_tokens` answered locally and
flagged, `tool_choice` and `cache_control` handled with a note, URL
images inlined, documents refused loudly. Each preset's gap list is
verified against the provider's own docs — recipe:
`docs/recipes/native-endpoints.md`.

**The published matrix and the replay.** `docs/compatibility.md` is the
whole source × target × feature matrix, rendered by `npm run matrix`
from the pair tests; CI regenerates it and fails on drift. A weekly job
installs the newest Claude Code and Codex, replays their recorded
shapes through the gates, and opens an issue on any drift — the badge
on the matrix shows the last green run.

**Signed, auditable releases.** The container image is cosign-signed
in CI and every release attaches a maintainer-generated CycloneDX
SBOM; the npm package is published by hand. Provider SDKs stay
devDependencies: the runtime is Express, pino, pino-http, zod, yaml,
dotenv, prom-client and OTel — small enough to read.

**Embeddings, minimal.** `POST /v1/embeddings` in OpenAI format, routed
to OpenAI-compatible, Gemini or Ollama targets.

## Why not LiteLLM / claude-code-router / OpenRouter?

Use them — they're good tools, and for most people they may be the
right ones. LiteLLM covers 100+ providers with budgets and SSO;
claude-code-router is a friendly desktop app for Claude Code users;
OpenRouter is zero-infrastructure with hundreds of models on one key.
What none of them publishes is per-pair conformance evidence: babelgate
is the one to pick when you need to *check* the translation — the
generated matrix, the per-request inspector, and the declared-gap shim
are the difference. The full comparison, with dates and primary
sources: [docs/comparison.md](../comparison.md).

## Proven, not promised

Release gates rerun Claude Code's real edit task through each new path
[pending gates A/B/C, Task 17 — owner fills results]:

- **Gate A** — Claude Code on `gemini-3.8-flash` with thinking on,
  reasoning carried across a three-turn tool loop
- **Gate B** — Claude Code through Ollama's native Anthropic endpoint
  in pass-through, `ollama-anthropic` preset gaps fixed
- **Gate C** — the weekly client-replay green on the current Claude
  Code and Codex releases, and the published matrix up to date

## Honest edges

- Embeddings are OpenAI-format inbound only; audio and image
  generation are out.
- Pass-through exists for Anthropic and OpenAI Chat sources — Gemini
  and Ollama same-format shim paths wait for demand.
- Documents a target can't read are refused, not text-extracted.
- Reasoning stays bound to its origin: a mid-session fallback to
  another provider drops foreign signatures with a `reasoning_dropped`
  note and disables thinking for that request.

## Get started

```bash
OLLAMA_API_BASE_URL=http://localhost:11434 \
  npx babelgate --preset claude-code --target ollama --model qwen3-coder:30b
```

matrix is the contract: [docs/compatibility.md](../compatibility.md).
