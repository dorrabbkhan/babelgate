Devin sandbox: `~/.npm` is read-only, and the `npm_config_*`/`NPM_CONFIG_*` proxy env vars point at a per-session local port that refuses connections; the working proxy is `http_proxy`/`https_proxy` (localhost:3128). Run npm/npx with `npm_config_proxy=$HTTP_PROXY npm_config_https_proxy=$HTTPS_PROXY` (verified: `npm ping` → PONG). With that, `scripts/ci/smoke-pack.sh` passes on an empty temp cache — no `cp -r ~/.npm` needed: `npm_config_cache=$(mktemp -d) npm_config_proxy=$HTTP_PROXY npm_config_https_proxy=$HTTPS_PROXY scripts/ci/smoke-pack.sh`. Each exec command runs in its own PID and network namespace, so a backgrounded server (`npm run dev`, `scripts/babelgate-loop.sh watch`) dies or is unreachable from the next command — start the server and its curl in the same command; if the watcher still can't run, use `gh pr checks <PR> --watch` in the foreground before the final summary. `gh pr edit` fails (Projects-classic deprecation, `repository.pullRequest.projectCards`); update PR bodies with `gh api -X PATCH repos/{owner}/{repo}/pulls/<n> -F body=@file`.
